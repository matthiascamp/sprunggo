# Generated imagery

The site uses six revised visualisations made with the built-in image generation tool. The bounce attachment visuals were based on the original `detail.jpg` prototype photo. Five bounce images were revised to show the low, compact supports visible in that photo instead of tall exposed spring towers. The walk/run visual was based on the original `walk-run-reference.jpg` photo from the current site.

| Asset | Final image direction |
| --- | --- |
| `studio-hero-lettered.webp` | Dark studio photograph of two prototype attachments, each with the exact side words WALK (yellow), RUN (green), BOUNCE (red). Preserve the device shape and lime straps. |
| `studio-hero-wide.webp` | Wide dark studio composition of two prototype attachments, each fully visible with WALK (yellow), RUN (green), BOUNCE (red) on the outer side rail. Used for the desktop hero; the portrait image remains the phone source. |
| `studio-detail-lettered.webp` | Close studio detail of one attachment on warm stone, with WALK RUN BOUNCE printed on its visible outer side rail. |
| `lifestyle-concept-lettered.webp` | In-use visualisation of the attachments beneath white sneakers on a sunlit court, each showing WALK RUN BOUNCE on the side. |
| `side-visual-lettered.webp` | Side-profile studio visualisation of the attachment on a charcoal plinth, with WALK RUN BOUNCE on the outer rail. |
| `walk-run-studio.webp` | Studio treatment of the real walk/run prototype photo, keeping the black fabric uppers, wide black instep straps, compact under-shoe supports, and yellow WALK / green RUN side lettering. |

The original photos are included as `detail.jpg` and `walk-run-reference.jpg`. The reference photos do not fully expose the internal spring mechanisms, so generated scenes remain visualisations rather than engineering-accurate records. Verify the under-platform construction against the physical prototypes before using the images as product specifications.
