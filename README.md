# Sprung-Go redesign

A standalone, responsive landing page redesign for [sprung-go.com.au](https://sprung-go.com.au/). Open `index.html` to review it locally, or serve this directory with any static HTTP server.

## What changed

- Rebuilt the page around the actual partnership goal: explain the platform, distinguish current prototype from future concepts, and invite manufacturer/distributor enquiries.
- Replaced dead `#` calls to action with working section links and a preaddressed email enquiry.
- Created a new visual system with bold editorial type, strong colour, responsive layouts, mobile navigation and prototype visualisations with the side lettering.
- Brought over the original site's product story, partnership and patent copy, three playable prototype videos, and two original concept artworks while retaining the real prototype photographs.
- Added a transparent hero product cutout with a CSS glow. The site header remains in its existing design.

## Publishing

This is a static site. It has **not** been installed into the live WordPress instance. To put it on sprung-go.com.au, either deploy these files as the site root or rebuild this layout in the existing WordPress theme/page builder. The email call to action works without a backend; it opens the visitor's email app.

The original product photos and videos came from the site's public WordPress media library. The generated imagery is labelled on the page and should be reviewed by the product owner before public use, since visualisations can differ from the physical prototype. The fourth video referenced by the WordPress homepage was unavailable at its source URL.
